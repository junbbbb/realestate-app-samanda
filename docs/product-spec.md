# Product Specification

## Target User
개인 부동산 사무소를 혼자 운영하는 이모님. 마포구 상가/건물 매물을 매일 네이버에서 확인하는 수고를 줄이고 싶다.

## Core Features

### 1. 대시보드 (홈)
- 오늘 새로 수집된 매물 수 표시
- 내 등록 매물 현황 (활성/계약중/완료)
- 최근 수집 매물 미리보기 5개
- 마지막 크롤링 시간

### 2. 매물 검색
- 네이버 수집 매물 + 내 매물 통합 검색
- 필터: 유형(상가/건물), 거래(매매/임대), 가격, 면적, 층수, 키워드
- 정렬: 가격순, 면적순, 최신순, 층순
- 매물 카드에 주소, 가격, 면적, 층, 유형 표시
- 카드 클릭 시 상세 보기

### 3. 내 매물 관리
- 매물 등록 (주소, 가격, 면적, 층, 사진, 설명)
- 매물 수정
- 상태 변경 (활성 → 계약중 → 완료)
- 매물 삭제

### 4. 자동 크롤링
- 매일 새벽 4시 네이버 부동산에서 마포구 매물 자동 수집
- 중복 매물 자동 제거
- 새 매물/가격 변동/삭제 매물 추적

## UI/UX
- Base Web (Uber UI) 컴포넌트 사용
- 모바일 반응형
- 하단 네비게이션: 대시보드, 매물 검색, 내 매물, 설정
- 한국어 인터페이스
